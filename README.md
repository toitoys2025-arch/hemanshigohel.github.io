# Hemanshi Gohel — Digital Marketing Portfolio

A responsive personal portfolio website built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — portfolio content and structure
- `style.css` — responsive design, animations and dark mode
- `script.js` — mobile menu, theme toggle and scroll animations

## GitHub Pages
1. Create a GitHub repository named `YOURUSERNAME.github.io`.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save and wait for GitHub Pages to publish.

## Before publishing
Replace:
- `your.email@example.com`
- LinkedIn `#`
- Instagram `#`
- Sample project cards with your real work
- The `HG` profile placeholder with your photo if desired
